# Python_practical


## ✅ **Part I: Core Python (Basics & Intermediate)**

1. Convert Celsius to Fahrenheit and vice versa.
2. Swap two variables without using a temporary variable.
3. Convert Decimal to Binary, Octal, and Hexadecimal.
4. Simple calculator using functions.
5. Find max and min of three user-input numbers.
6. Enter 10 numbers and display the largest odd number (or message if none).
7. Check if a number is an Armstrong number.
8. Check if a number is a palindrome.
9. Perform string operations:

   * Count vowels
   * Count length (without `len()`)
   * Reverse string
   * Find and replace
   * Palindrome check
10. Print histogram of a list of integers, e.g., `histogram([4,9,7])`.
11. Fibonacci series using recursive function.
12. Factorial using recursive function.
13. Demonstrate:

* `readline()`, `readlines()`
* `writeline()`, `writelines()`
